XPIsland 0.7.2 for World of Warcraft: Forever 1.60.1 (Interface 16001).

- Fix the settings presentation after the framework migration: align labels and fields in compact rows, highlight the selected tab, and use matching themed dropdowns, checkboxes, inputs, sliders and scrollbars.
- Reduce the settings window to 560 × 520 UI units and remove duplicate page headings. Behavior fits without scrolling at ordinary viewport sizes; short windows retain scrolling.
- Move placement/reset controls to Appearance and shared/character profile shortcuts to Profiles. Preserve settings, profile commands and timer behavior.
- Pin the bundled SomethingNeedDoing runtime to the reviewed source commit recorded in UPSTREAM.json (0.4.2 development source). Keep bundled files byte-identical to that commit.

Offline validation covers page geometry, fonts, theme changes, disabled durations, profile shortcuts, scrolling, reopening, runtime behavior and package integrity. Native rendering/input, combat/taint safety and in-game performance remain unverified. This is a local candidate, not a published release.
