XPIsland 0.4.2 for World of Warcraft: Forever 1.60.1 only.

- Expanded stat tooltips now appear after hovering the same cell for two seconds.
- Leaving or switching cells hides the tooltip immediately and cancels its pending timer. Each new hover starts the full delay, including returning to the same cell.
- Collapsing, combat auto-collapse, hiding, dragging and profile layout changes cancel pending stat tooltips. Stale callbacks cannot reopen them.
- Tooltip content, styling and the collapsed bar's immediate tooltip remain unchanged. The delay uses one cancellable timer with no permanent per-frame polling.

155 focused hover assertions cover all eight cells, timing boundaries, rapid movement, same-cell re-entry, stale callbacks, dismissal and bounded resources. Native hover behavior remains an in-game acceptance check after reloading.
