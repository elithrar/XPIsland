XPIsland 0.6.0 for World of Warcraft: Forever 1.60.1 only (Interface 16001).

- Add one compact inline row for pet XP, PvP rank progress and estimated kills to level, with individual visibility controls in Tracking settings.
- Add optional Honor & PvP tracking with separate available Honor and Rank Points, native rank ceilings and an opt-in switch at the player level cap. Experience remains the default mode.
- Add a kills-to-level label based on confirmed kill rewards from the last hour, weighting the newest 20 minutes twice. At least five comparable kills are needed; the estimate adapts to rewards and does not forecast rested XP exhaustion.
- Preserve existing profiles, XP accounting and played-time data. Valid kill history survives reloads and short reconnects; an explicit session reset clears it.

Offline regression coverage includes pet replacement and events, missing/restricted progression values, rank ceilings, mode transitions, kill reconciliation and deduplication, saved-history recovery, layout bounds and timer/frame ownership. The release workflow runs Lua suites, release guards and deterministic package validation.

Live-client validation remains NOT RUN. Native rendering, real pet/Honor/rank event ordering, localized kill messages, restricted values and taint alongside other addons still need in-game acceptance. See docs/PROGRESSION-LIVE-CHECKLIST.md in the source repository. Restart WoW after installation.
